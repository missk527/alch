ALCH10. Oxidation and Reduction

Key Notes (Synced with Video)

Electron Transfer and Redox
  • Oxidation is loss of electrons; reduction is gain of electrons. Remember OIL RIG: Oxidation Is Loss, Reduction Is Gain.
  • A redox reaction involves oxidation and reduction together: electrons lost by one species are gained by another.
  • An oxidizing agent accepts electrons and is reduced; a reducing agent donates electrons and is oxidized.
Oxidation Numbers
  • An oxidation number tracks the formal charge assigned to an atom. An uncombined element has oxidation number 0; a simple ion has the same oxidation number as its charge.
  • In these examples, hydrogen in compounds is usually +1 and oxygen is usually −2; oxygen in hydrogen peroxide is −1.
  • Oxidation increases oxidation number; reduction decreases oxidation number. The sum of oxidation numbers is 0 for a neutral compound.
Nitrogen, Hydrogen and Ammonia
  • In N₂ and H₂, both elements have oxidation number 0.
  • In NH₃, hydrogen is +1, so nitrogen is −3 because x + 3(+1) = 0.
  • Nitrogen changes from 0 to −3 and is reduced; hydrogen changes from 0 to +1 and is oxidized.
Metals Reacting with Acids
  • A reactive metal is oxidized while hydrogen ions from the acid are reduced to hydrogen gas.
  • For sodium reacting with hydrochloric acid, sodium changes from 0 to +1 and hydrogen changes from +1 to 0.
  • For magnesium reacting with sulfuric acid, magnesium changes from 0 to +2 and hydrogen changes from +1 to 0. Both are redox reactions.
Disproportionation
  • In a disproportionation reaction, the same element is both oxidized and reduced.
  • During hydrogen peroxide decomposition, oxygen starts at −1 in H₂O₂. Some oxygen becomes 0 in O₂ and is oxidized; some becomes −2 in H₂O and is reduced.
  • The balanced equation is 2H₂O₂ → 2H₂O + O₂.
Worked Oxidation Number Examples
  • For Zn + CaCO₃ → ZnO + CaO + CO, zinc changes from 0 to +2 and is oxidized; carbon changes from +4 in CaCO₃ to +2 in CO and is reduced. Calcium stays +2.
  • For 2NH₃ + NaClO → N₂H₄ + NaCl + H₂O, nitrogen changes from −3 in NH₃ to −2 in N₂H₄ and is oxidized; chlorine changes from +1 in NaClO to −1 in NaCl and is reduced.
  • In hydrazine, hydrogen is +1; using 2x + 4(+1) = 0 gives nitrogen an oxidation number of −2.
